# 连小理 · 校园智能物料生成平台

大连理工大学「人工智能应用与设计大赛」参赛作品。单文件 Web 应用，直接托管在 GitHub Pages。

**在线地址：<https://adastrahole.github.io/>**

## 功能

- **宣传物料**：先填文字 → 实时排版预览与编辑；模板 = 风格 + 渠道合并；支持对话式微调海报、导出 PDF
- **简历工作台**：空白新建 / 模板创建 / 文本导入 / JSON 导入，编辑器实时预览，导出 PDF
- **AI 助手**：BYOK（自带模型 Key），同一份 API 配置可生成口号、润色推文、写简历
- **品牌资产库**：校徽、品牌色、字体规范与历史产出，保证物料视觉一致
- **技能插件**：导入含 `SKILL.md` 的技能包，扩展策划 / 设计 / 文案能力
- **多智能体协作**：策划·文案 → 设计 → 审核 → 过程档案

## 数据

所有数据默认存于浏览器本地（localStorage），离线可演示。可选接入：

- 本地后端 `server/index.js`（检测不到时自动降级为本地存储）
- Supabase 云数据库（在「设置」里填 URL 与 anon key 即可前端直连）

## 部署

仓库名 `adastrahole.github.io`，GitHub Pages 自动从 `main` 分支根目录发布，无需额外配置。

更新流程：改 `index.html` → 提交到 `main` → 等 Actions/Pages 构建完成（约 1 分钟）→ 刷新线上地址。
